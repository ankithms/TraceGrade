# API Contract

Base path: `/api/v1`

JSON is used for requests and responses. Timestamps are UTC ISO 8601 strings. IDs are UUIDs. The OpenAPI document generated by FastAPI is the executable reference; this file defines the frozen resource surface before implementation.

## Authentication

- Admin operations: `X-TraceGrade-Admin-Key: <admin-key>`.
- Project operations: `Authorization: Bearer <project-api-key>`.
- Health endpoints require no authentication.

Project API keys are returned once at creation. All project-scoped resource IDs are checked against the authenticated project.

## Response Conventions

- Create: `201 Created`, except experiment start which returns `202 Accepted`.
- Read/update: `200 OK`.
- Delete/revoke: `204 No Content`.
- Validation: `422 Unprocessable Entity`.
- Authentication: `401 Unauthorized`; cross-project or unknown resources return `404 Not Found`.
- Conflict/idempotency mismatch: `409 Conflict`.

Errors use:

```json
{
  "error": {
    "code": "stable_machine_code",
    "message": "Human-readable summary",
    "request_id": "uuid"
  }
}
```

Collection endpoints accept `limit` (default 50, maximum 100) and `offset` (default 0) and return `{ "items": [], "total": 0 }`.

## Projects and API Keys

| Method | Path | Auth | Purpose |
| --- | --- | --- | --- |
| `POST` | `/projects` | Admin | Create a project. |
| `GET` | `/projects` | Admin | List projects. |
| `GET` | `/projects/{project_id}` | Admin | Read a project. |
| `PATCH` | `/projects/{project_id}` | Admin | Rename a project. |
| `DELETE` | `/projects/{project_id}` | Admin | Delete a project and owned data. |
| `POST` | `/projects/{project_id}/api-keys` | Admin | Create and reveal one API key. |
| `GET` | `/projects/{project_id}/api-keys` | Admin | List safe key metadata. |
| `DELETE` | `/projects/{project_id}/api-keys/{key_id}` | Admin | Revoke a key. |

## Traces and Spans

| Method | Path | Purpose |
| --- | --- | --- |
| `POST` | `/traces` | Idempotently create or update a trace by `external_id`. |
| `GET` | `/traces` | List traces for the authenticated project. |
| `GET` | `/traces/{trace_id}` | Read a trace with spans. |
| `POST` | `/traces/{trace_id}/spans` | Idempotently create or update one span. |
| `POST` | `/traces/{trace_id}/spans/batch` | Ingest an SDK batch. |

Payloads expose the trace/span fields in `docs/db-schema.md`. Batch requests contain at most 100 spans and return accepted IDs plus item-level validation errors.

## Evaluators

| Method | Path | Purpose |
| --- | --- | --- |
| `POST` | `/evaluators` | Create an exact-match, contains, JSON-match, or Gemini-judge evaluator. |
| `GET` | `/evaluators` | List evaluators. |
| `GET` | `/evaluators/{evaluator_id}` | Read validated configuration. |
| `PATCH` | `/evaluators/{evaluator_id}` | Update future-use configuration. |
| `DELETE` | `/evaluators/{evaluator_id}` | Delete an evaluator not used by a running experiment. |

Gemini-judge configuration stores a rubric and score/pass criteria. It does not expose provider routing or a prompt-management system.

## Experiments and Results

| Method | Path | Purpose |
| --- | --- | --- |
| `POST` | `/experiments` | Snapshot configuration and start a Temporal workflow; returns `202`. |
| `GET` | `/experiments` | List experiments, filterable by status/dataset. |
| `GET` | `/experiments/{experiment_id}` | Read status and aggregate progress. |
| `GET` | `/experiments/{experiment_id}/results` | List case-level results and evaluator scores. |
| `POST` | `/experiments/{experiment_id}/cancel` | Request cancellation of a non-terminal workflow. |

`POST /experiments` requires `dataset_id`, `name`, `version_label`, application execution configuration, and one or more `evaluator_ids`. Repeating the same request with the same client `idempotency_key` returns the existing experiment.

## Comparisons and Regressions

| Method | Path | Purpose |
| --- | --- | --- |
| `POST` | `/comparisons` | Compare completed baseline/candidate experiments and persist regression decisions. |
| `GET` | `/comparisons` | List prior comparisons. |
| `GET` | `/comparisons/{comparison_id}` | Read metrics, deltas, thresholds, and regressions. |

Comparison input contains `baseline_experiment_id`, `candidate_experiment_id`, and thresholds for quality decrease, latency increase, and cost increase. Both experiments must belong to the authenticated project and be complete.
